# Support

Habi is maintained by one developer (Alvin Cris Tabontabon) in their own time. Issues and
pull requests are read, but responses are best effort; security reports come first. There is
no support agreement and no guaranteed response time.

## Where to ask

- **A question, or not sure it is a bug:** start a
  [discussion](https://github.com/acltabontabon/habi/discussions), or open an issue with the
  *Question* form.
- **A bug:** open an issue with the *Bug report* form. The steps to reproduce it and a
  diagnostic report (Settings → Diagnostics → Preview report, or `habi diagnostics`;
  redacted, and shown to you before saving) help most.
- **An idea:** open an issue with the *Idea or request* form. Check the
  [product contract](docs/project/product.md) first; some things Habi avoids on purpose.
- **A security problem:** do not open an issue. Follow [SECURITY.md](SECURITY.md).

Before asking, see the [known limitations](docs/project/security-model.md#known-limitations); the
[documentation](docs/README.md) covers everyday use.
